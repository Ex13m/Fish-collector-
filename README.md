# FISH COLLECTOR™ 🎣

**Поймал → сфоткал → собрал.** Современное single-file PWA: любая рыба превращается в коллекционный **die-cut стикер** — приложение вырезает фон, добавляет белую обводку и подпись. Главный экран — набор твоих стикеров; тап раскрывает карточку с размером, местом, датой и фото оригинала. Стикеры можно скачать и заказать наклейками.

> Для **любой** рыбы и любых вод. Без сервера, без ключей, работает офлайн, ставится на главный экран. RU / EN / NO.

## Как это работает
1. **Снимаешь рыбу** (камера или галерея).
2. **Авто-вырезка фона** — нейросеть `@imgly/background-removal` прямо в браузере (модель грузится один раз по CDN, потом кэшируется офлайн). Если ИИ недоступен — простая вырезка по краям (flood-fill) или «без вырезки».
3. **Белая обводка** (die-cut) добавляется на canvas → получается стикер.
4. **Вводишь данные:** название рыбы (на выбранном языке, с автоподсказками), размер, количество, дата-время, место (кнопка GPS), способ, заметка.
5. Новый стикер влетает в коллекцию с празднованием и конфетти.

## Главный экран
Сетка стикеров (вырезка + белая обводка) в стиле «инвентаря»; под каждым — **размер · место · дата**, трофей 🏆 у рекордной по виду рыбы. Сортировка: по размеру / свежие / по виду / трофеи. Сверху — прогресс коллекции (стикеров, видов, рекорд см, мест, трофеев).

## Карточка стикера
Тап → стикер «приближается» (spring-зум + 3D-tilt по мыши/гироскопу): размер, рекорд вида, когда, место, способ, заметка и **фото оригинала**. Кнопки: ещё поимка · скачать стикер · заказать наклейки · удалить.

## Стикер на скачивание / заказ
PNG die-cut: вырезка + белая обводка + **подпись (имя + размер)**, впечатанная в наклейку. Заказ физических наклеек — через сервис владельца (форма → письмо).

## Стек
- Один файл `index.html` — vanilla JS, без сборки. Внешка: Google Fonts (Anton / Oswald / Archivo / Space Mono) + ИИ-модель вырезки фона по CDN (lazy).
- Данные: метаданные в `localStorage` (`fishcollector_catches_v2`), **изображения в IndexedDB** (стикер + оригинал) — без лимита localStorage.
- PWA: `manifest.json` + `sw.js` (офлайн-кэш статики и модели, HTML — network-first).
- Дизайн: холодная «cold-ops» палитра (slate-blue монохром) + плавные spring/FLIP-переходы — **из референса взяты только цвет и переходы**, концепция авторская.

## Деплой
**A. ZIP на Netlify:** `zip -j fish-collector.zip index.html manifest.json sw.js icon.svg netlify.toml` → перетащить в Netlify.
**B. git + Netlify** (рекомендуется): импорт репозитория, publish = корень (`netlify.toml` готов).

> Камера/GPS требуют **HTTPS** (Netlify даёт автоматически). При релизе бампать `APP_VERSION` (index.html) и `V` (sw.js) — скил `bump-version`.
