# FISH COLLECTOR™ 🎣

Современный **single-file PWA-каталогизатор поимок**. Собирай рыбу как голографические стикеры-образцы, открывай детальные карточки, скачивай и заказывай наклейки. Холодная «cold-ops» эстетика северных вод (Хитра, Норвегия · 63.66°N 8.80°E).

> Красиво открывается по ссылке, работает офлайн, ставится на главный экран.

## Что внутри
- **Главный экран = инвентарь.** Виды-«образцы» отсортированы по значимости (редкость → собранные выше). Пойманные — в цвете с трофеем 🏆, не открытые — затемнённый силуэт `?????`.
- **Тап по стикеру → карточка-образец.** Рыба «приближается» (spring-зум + 3D-tilt по мыши/гироскопу), раскрывается досье: глубина, местообитание, как ловить, рекорд длины/веса и **журнал поимок** — дата/время, место (GPS), длина, расчётный вес, способ, фото оригинала, заметка.
- **Запись поимки.** Вид, длина, количество, дата-время, место (кнопка GPS), способ/приманка, фото (сжимается в браузере), заметка. Новый вид → анимация-празднование + конфетти.
- **Стикеры.** Скачивание PNG die-cut наклейки (рендер на canvas) и **заказ физических наклеек** через сервис владельца (форма → письмо).
- **Расчёты.** Вес считается из длины по видовым коэффициентам `W = a·Lᵇ`, трофей определяется автоматически (рекорд по виду).

## Стек
- Один файл `index.html` — vanilla JS, без сборки. Внешка — только Google Fonts (Anton / Oswald / Archivo / Space Mono).
- Данные пользователя — `localStorage` (`fishcollector_catches_v1`).
- PWA: `manifest.json` + `sw.js` (офлайн-кэш статики, HTML — network-first).
- Дизайн: холодная стально-синяя палитра, сжатая editorial-типографика, технические mono-подписи, срезанные углы, штрихкод, выцветшие горы — много spring/FLIP-анимаций.

## Дизайн-направление
Холодный «COLD OPS» lookbook: приглушённый slate-blue монохром + плавные переходы (цвет и переходы — по референсу заказчика), концепция коллекции-стикеров — авторская.

## Деплой
**A. drag-and-drop ZIP на Netlify** (без git):
```bash
zip -j fish-collector.zip index.html manifest.json sw.js icon.svg netlify.toml
```
Перетащить `fish-collector.zip` в Netlify → Deploys.

**B. git + Netlify** (рекомендуется): запушить репозиторий, в Netlify «Add new site → Import from Git», publish directory = корень (`netlify.toml` уже настроен).

> При каждом релизе бампать `APP_VERSION` в `index.html` и `V` в `sw.js` (скил `bump-version`), иначе SW отдаст старую версию.

## Структура
```
index.html      — приложение целиком
manifest.json   — PWA-манифест
sw.js           — service worker (офлайн-кэш)
icon.svg        — иконка
netlify.toml    — конфиг автодеплоя (no-cache для sw.js)
.claude/skills/ — служебные скилы (deploy-zip, bump-version, mobile-check)
PROJECT.md      — технический передаточный документ
```
