# Мобильная полировка (single-file PWA)

Сайт — один `index.html` (CSS + JS внутри). Цель: на телефоне ничего «не едет», не вылезает за край. Тестовые ширины — **360px** и **390px**, плюс десктоп **≥1100px** (проект должен быть красив и в вебе).

## Где смотреть
- Шапка: `.top` (бренд, `nav` mono-ссылки, `.oct` кнопка заказа). На `max-width:640px` `nav` скрыт.
- Герой: `.hero` (grid `1.15fr .85fr` → 1 колонка на `max-width:760px`), `.feat` панель-статистика.
- Сетка: `.grid` (`auto-fill minmax(176px,1fr)` → 2 колонки на `max-width:440px`).
- Модалки `.sheet` — центрированы, `width:min(460px,94vw)`, скролл внутри.

## Чек-лист
1. **Горизонтальный оверфлоу.** Ничего не выходит за `100vw`. Гигантская типографика `.anton`/`.hero h1` — проверить `font-size: clamp()` на 360px, чтобы заголовок не пушил ширину (перенос `<br>` уже есть).
2. **Тач-таргеты ≥ 40×40px** (`.oct`, `.chip`, `.btn`, `.fab`, `.qty button`).
3. **Срезанные углы (clip-path notch) не режут текст** — паддинги внутри `.frame`/`.sheet`/`.btn` с запасом.
4. **Safe-area.** Фикс-элементы снизу — `bottom:calc(N + env(safe-area-inset-bottom))` (`.fab`, `#toast`). `#app` имеет `padding-bottom` с safe-area.
5. **Скролл-ленты** (`.tools`, `.top nav` при наличии) — `overflow-x:auto`, `scrollbar-width:none`.
6. **Модалки** — `max-height:92vh; overflow-y:auto`; при открытии `body{overflow:hidden}` (уже в `openSheet`).
7. **Десктоп.** На широком экране `.grid` заполняет ряд ровно (minmax), `.hero` двухколоночный, `max-width:1280px` контейнер по центру.
8. **prefers-reduced-motion** — анимации гасятся (media-правило в конце CSS).

## После правок
1. `node --check` по `<script>` из `index.html`.
2. Бампнуть версию (скил `bump-version`) — иначе старый UI из кэша SW.
3. Деплой (скил `deploy-zip`) или git-push.

## Правило
Любое UI-изменение = бамп версии. Без этого правка не доедет до пользователя (SW/кэш).
