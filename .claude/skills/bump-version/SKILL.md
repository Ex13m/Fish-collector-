# Бамп версии (обход кэша service worker)

Известная болячка PWA: после деплоя service worker отдаёт старую версию. Фикс — синхронно поднять версию в двух местах.

## Шаги
1. В `index.html` найти строку:
   ```js
   const APP_VERSION='X.Y.Z';
   ```
   Поднять патч/минор (например `1.0.0` → `1.0.1`).
2. В `sw.js` найти строку:
   ```js
   const V = 'fishcollector-vX.Y.Z';
   ```
   Поставить **ту же** версию, что и `APP_VERSION` (`fishcollector-v1.0.1`).
3. Проверить JS: извлечь `<script>` из `index.html`, `node --check`.
4. Готово — дальше сборка (`deploy-zip`) или git-коммит.

## Правила
- Версии в `index.html` и `sw.js` должны совпадать.
- Семвер: багфикс → патч, новая фича → минор, ломающее → мажор.
- Менять версию при КАЖДОМ деплое, иначе у пользователей останется старый кэш.
